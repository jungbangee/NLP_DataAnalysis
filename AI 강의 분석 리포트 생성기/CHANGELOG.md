## v0.3.0 — 2026-06-26

### 새 기능

#### 1. 일괄 업로드 (dashboard.html, server.js)
- 강의 분석 페이지에 **단일 / 일괄** 탭 추가
- `.txt` 파일 여러 개를 한 번에 선택해 순차 분석
- 파일별 실시간 진행 로그 표시 (현재 파일 · 카테고리 단계)
- 취소 버튼 지원
- 서버 엔드포인트: `POST /api/analyze/bulk`

#### 2. 전체 평균 벤치마크 (instructors.html, server.js)
- 강사 목록 상단에 **전체 강사 평균 벤치마크** 바 차트 표시 (카테고리별 100점 환산)
- 강사 카드에 종합평가 등급(우수 / 양호 / 보통 / 미흡 / 부족) 색상 배지 표시
- 서버 엔드포인트: `GET /api/benchmark`, `GET /api/instructor-grades`

#### 3. 강사 목록 필터 (instructors.html)
- **등급 필터**: 우수 / 양호 / 보통 / 미흡 / 부족
- **과목 필터**: DB 데이터 기반 자동 목록 생성
- **초기화** 버튼

#### 4. 강사 비교 날짜 범위 필터 (comparison.html)
- 시작일 ~ 종료일 날짜 입력으로 비교 데이터 범위 지정
- 필터 적용 시 모든 탭(카테고리 비교, 날짜별 추이, 강사 갭 분석, 성장률, 총평) 즉시 업데이트
- 초기화 버튼으로 전체 기간 복원
- 현재 필터 적용 현황(N명 / N건) 표시

#### 5. 강의 이력 페이지네이션 (instructor.html)
- 강사 개인 페이지 강의 이력에 **5개 / 10개 / 20개 / 전체** 표시 개수 선택
- ◀ ▶ 페이지 이동 버튼 + 현재 페이지 표시
- 강의 삭제 시 첫 페이지로 자동 이동

#### 6. 분석 이력 필터 확장 (dashboard.html)
- 강사명 검색 (기존 유지)
- **과목명 검색** 추가
- 단일 날짜 → **날짜 범위(시작 ~ 종료)** 로 변경
- **10개 / 20개 / 50개 / 전체** 표시 개수 선택 + 페이지네이션

### 버그 수정

| 항목 | 내용 |
|------|------|
| DOCX 차트 복원 | 오프스크린 Canvas에 별도 Chart 인스턴스를 생성해 원본 차트를 건드리지 않도록 수정 (instructor.html) |
| 레이더 차트 흰 배경 | DOCX 내보내기 시 차트 레이블 검정색 + 흰 배경으로 캡처 (analysis.html, instructor.html) |
| 비교 날짜 필터 차트 오류 | `applyDateFilter`에서 `build*` 대신 `upd*` 함수를 사용해 Chart 인스턴스 충돌 수정 |
| 분석 이력 필터 날짜 경계 | 종료일 당일 데이터 누락 방지 (`d <= to` → `d < toNext` 방식으로 변경) |
| 강의 삭제 시 InstructorSummary 미삭제 | 강의 삭제 후 해당 강사의 남은 강의가 없으면 `instructorsummaries`도 자동 삭제 |
| 종합평가 생성 취소 오류 로그 | 취소 시 오류 메시지 출력 안 되도록 `cancelled` 플래그 처리 |
